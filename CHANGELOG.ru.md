# Журнал изменений

[Română](CHANGELOG.md) · [English](CHANGELOG.en.md) · **Русский**

Важные изменения в каждой версии. Нумерация следует
[Semantic Versioning](https://semver.org/lang/ru/).

## [3.0.6] — 2026-10-24

### Добавлено

- В окне **Помощь**: ссылки на сайт программы, адрес почты и исходный код,
  с подписями на языке интерфейса.

### Изменено

- Образ `.dmg` для macOS содержит только приложение и ярлык *Applications*;
  лицензии находятся внутри приложения, а примеры — в меню **Примеры**.

## [3.0.5] — 2026-10-24

### Исправлено

- Ссылки в окне **Помощь** открываются в браузере (адрес почты — в почтовой
  программе).

## [3.0.4] — 2026-10-24

### Исправлено

- Кенгуренок в верхнем ряду поля виден целиком: на больших экранах
  (например, на Mac) у него обрезались уши.
- Меню **Настройки** остаётся открытым, пока вы отмечаете флажки, и
  закрывается щелчком вне меню.

## [3.0.3] — 2026-10-23

### Добавлено

- Установщик `.msi` для Windows: папку установки можно изменить, а флажок
  (отмечен по умолчанию) создаёт ярлык Cangurul на рабочем столе. Без окон:
  `msiexec /i cangurul-*.msi /qn INSTALLFOLDER="D:\Cangurul"
  DESKTOPSHORTCUT=""`.

### Изменено

- Окна установщика `.msi` на румынском, без страницы с лицензией.
- Новая версия устанавливается в папку, выбранную при прошлой установке.

## [3.0.2] — 2026-10-22

### Добавлено

- Кнопка **Форматировать** (Ctrl+Shift+F): расставляет отступы и переносит на
  отдельные строки команду после `ЕСЛИ` и `ИНАЧЕ`. Курсор остаётся у того же
  слова, а Ctrl+Z отменяет форматирование целиком.
- Подсказки при наборе: после `пок` появляются `ПОКА НЕ КРАЙ …`,
  `ПОКА КРАЙ …` и остальные условия; `ВЫПОЛНИТЬ` предлагает процедуры
  программы, а `КОНЕЦ` — конец открытого блока. Выбор — стрелками ↑/↓ и Enter
  или Tab либо мышью; Esc закрывает список.
- Enter сохраняет отступ блока; `КОНЕЦ` и `ИНАЧЕ` сами выравниваются по началу
  блока.

### Изменено

- Кнопки команд: команда получает отступ блока, в который попадает, пример
  внутри (`ШАГ`, `ПОВОРОТ`, `Имя`) остаётся выделенным, чтобы следующая
  команда его заменила, а после простой команды курсор переходит на новую
  строку.
- `ЕСЛИ` вставляется на нескольких строках, вместе с `ИНАЧЕ`; после команды
  под `ЕСЛИ` выделяется команда под `ИНАЧЕ`.
- Примеры отформатированы.

### Исправлено

- Копирование и вставка (Ctrl+C, Ctrl+X, Ctrl+V) работают и с другими
  программами.
- Курсор больше не пропадает из редактора после нажатия на кнопки команд и на
  **Исправить**.
- При щелчке в списке проблем ошибочное слово остаётся выделенным.

## [3.0.1] — 2026-10-22

### Добавлено

- Установщик `.msi` для 64- и 32-битной Windows 10/11: меню «Пуск»,
  связь с файлами `.cng`, обновление поверх старой версии.
- README на английском и русском.

### Изменено

- Кнопки команд расположены в два ряда: сначала действия, затем управляющие
  конструкции.

### Исправлено

- Портативный архив для Windows: тексты лицензий читаются правильно (UTF-8).

## [3.0.0] — 2026-10-20

Первая версия, переписанная на Rust по программе «Cangurul» (версия 2).
Файлы `.cng` из старой версии открываются и выполняются без изменений.

- Интерфейс на румынском, русском и английском, светлая и тёмная тема.
- Редактор с нумерацией строк, подсветкой синтаксиса и кнопками для вставки
  команд.
- Анимированное выполнение с подсветкой текущей строки; по шагам, пауза,
  регулируемая скорость или мгновенно.
- Анализатор проверяет программу во время набора и предлагает исправления.
- Размер поля настраивается; прыжки можно показывать пунктиром.
- Ключевые слова можно писать по-румынски, по-русски или по-английски, с
  диакритикой или без.
- Пакеты для Windows (включая Windows 7), Linux и macOS.
